# 三項服務功能正式化

依 2026-10-22 原始討論與 `lionclub-lab-v1` 原型恢復：活動成果包、獅友需求媒合、個人服務護照。持有人於 2026-11-10 明確要求上正式版；取代當時僅做獨立試用、不推 main 的階段限制。

## 正式資料契約

- 活動成果：沿用既有活動、實際報名／報到資料及活動管理授權；主辦補充結束時間、受益估計、數量、總服務時數與摘要，產出可下載的成果草稿。總時數不自動算入個人服務紀錄，不冒稱完成官方通報。
- 資源／需求：會員發布、其他會員回應，發布人或具範圍的有效幹部接受、確認完成；伺服器保存版本與稽核。封鎖關係應影響一般瀏覽與回應；聯絡方式不自動公開或交換。
- 服務護照：本人補登一律待確認；具組織授權的幹部確認或退回，不能自審。確認與待確認時數分開，獅年以臺北每年七月一日起算；匯出自己的服務履歷，和既有任職資歷分開。

## 實作順序

1. 新增結構、純驗證／狀態機、交易服務與權限測試。
2. 同一服務層接網站 Cookie 與原生 Bearer API，所有發布走現行條款與 Origin／Token 邊界。
3. 網站與原生 App 共用服務介面，提供清楚的載入、錯誤、取消、重試與衝突處理。
4. SQL 演練、權限／併發／防重複／跨會員資料隔離驗證；接續審查刪帳清理、政策與資料揭露。
5. 依精確正式目標、既有備份與鎖定機制套用新增遷移，再部署、驗收與產生新 App 建置。

不把原型角色切換、localStorage、合成會員或既有示範匯出帶入正式資料。不新增付費雲端資源、不啟用正式推播、不自行擴張 IAM 或旋轉既有金鑰。

Build 11 是本輪新功能開始前的修正候選，不能宣稱包含這三項正式功能；本輪完成後另核對 Apple 實際建置清單，選擇新的可追溯編號。
